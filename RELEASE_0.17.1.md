# Shelf Seasons 0.17.1

This small interaction release makes the Home library preview behave like the
book cards readers naturally expect to open.

## Included

- the complete cover-and-metadata card on Home opens the existing book editor;
- pointer, keyboard focus and pressed feedback cover the whole card;
- accessible open-book labels are localized in English and Russian;
- the separate Open library link continues to open the complete Library view.

## Manual setup

No database migration, environment variable or service configuration is needed.
