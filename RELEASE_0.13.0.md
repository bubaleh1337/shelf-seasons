# Shelf Seasons 0.13.0

This release adds original atmospheric seasonal backgrounds to the existing physical seasonal shelves.

## Included

- scroll-bound paper texture and layered seasonal light;
- large illustrated foliage around the page edges;
- unique spring, summer, autumn and winter still-life compositions;
- responsive placement that stays behind all controls and content;
- no external Pinterest assets or watermarks.

No new Supabase migration or Vercel environment variable is required.
