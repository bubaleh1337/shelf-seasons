# Запуск Shelf Seasons на Windows 11

В архиве находится версия `0.16.0`: исправленное переключение языка внутри аккаунта, Google OAuth, личная библиотека, поиск русских изданий, автоматический прогресс по текущей странице, календарь, итоги без дублей, сезонные полки, оптимизированная загрузка и зашифрованный ежедневный бэкап базы.

## 1. Распакуй проект

Распакуй архив `shelf-seasons-0.16.0-encrypted-database-backups-verified.zip` в:

```text
P:\Projects\shelf-seasons\shelf-seasons
```

Проверь, что `package.json` находится именно здесь:

```text
P:\Projects\shelf-seasons\shelf-seasons\package.json
```

После замены файлов выполни:

```powershell
.\UPDATE_TO_0.16.0.ps1
```

Скрипт удалит только локальный кэш сборки. `.env.local`, данные Supabase и пользовательские файлы он не затрагивает.

## 2. Установи зависимости

Открой Windows PowerShell:

```powershell
Set-Location P:\Projects\shelf-seasons\shelf-seasons
npm ci
```

## 3. Запусти приложение

```powershell
npm run dev
```

Открой локальный адрес, который появится в PowerShell. Корневая страница перенаправит на русскую версию `/ru/app`.

## 4. Что можно проверить

1. Переключай разделы: Главная → Библиотека → Календарь → Серии → Итоги → Настройки.
2. Нажми `Отметить чтение` и сохрани демо-отметку.
3. В Библиотеке используй поиск и фильтры статусов.
4. В Календаре переключай Неделю, Месяц и Год.
5. Нажми `EN`, чтобы проверить английскую версию.
6. Нажми значок луны, чтобы проверить тёмную тему.
7. Уменьши ширину окна, чтобы увидеть мобильную навигацию.

Рабочий `.env.local` останется на компьютере: обновляющий скрипт его не удаляет и не изменяет. Книги, чтение и сезонные привязки продолжают храниться в подключённом Supabase.

## 5. Проверка проекта

```powershell
npm run typecheck
npm run lint
npm test
npm run release:check
```

## 6. Подключение аккаунтов

Сначала убедись, что миграция 0.14.0 `supabase/migrations/202609090001_reading_progress_and_recap_deduplication.sql` уже применена. Затем один раз запусти миграцию 0.15.0 `supabase/migrations/202609090002_recap_library_choices.sql`. Для публичной беты рекомендуется добавить в Vercel серверную переменную `GOOGLE_BOOKS_API_KEY` с ограниченным ключом Google Books API.

## 7. GitHub

Репозиторий должен называться `shelf-seasons`. После добавления remote эта версия готова к обычному циклу commit → push → CI без дальнейшей передачи полного проекта архивами.

После push настрой два GitHub Actions секрета и проверь первый бэкап по
`docs/DATABASE_BACKUPS.md`. Приватный ключ age нельзя добавлять в репозиторий.
