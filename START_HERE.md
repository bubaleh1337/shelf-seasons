# Запуск Shelf Seasons на Windows 11

В архиве находится рабочая версия `0.5.2`: вход через Google, личная библиотека, улучшенный поиск русских изданий, отметки чтения, календарь, серии дней, корректная синхронизация статусов и конфигурация Vercel. Создавать новый чат или заново вставлять мастер-промпт не нужно.

## 1. Распакуй проект

Распакуй архив `shelf-seasons-0.5.2-vercel-auth-search-fix.zip` в:

```text
P:\Projects\shelf-seasons
```

Проверь, что `package.json` находится именно здесь:

```text
P:\Projects\shelf-seasons\package.json
```

а не во второй вложенной папке `shelf-seasons\shelf-seasons`.

## 2. Установи зависимости

Открой Windows PowerShell:

```powershell
Set-Location P:\Projects\shelf-seasons
npm ci
```

## 3. Запусти приложение

```powershell
npm run dev
```

Открой локальный адрес, который появится в PowerShell. Корневая страница перенаправит на русскую версию `/ru/app`.

## 4. Что можно проверить

1. Переключай разделы: Главная → Библиотека → Календарь → Серии → Итоги → Настройки.
2. Нажми `Отметить чтение` и сохрани демо-отметку.
3. В Библиотеке используй поиск и фильтры статусов.
4. В Календаре переключай Неделю, Месяц и Год.
5. Нажми `EN`, чтобы проверить английскую версию.
6. Нажми значок луны, чтобы проверить тёмную тему.
7. Уменьши ширину окна, чтобы увидеть мобильную навигацию.

Без `.env.local` книги и показатели остаются демонстрационными. После подключения `shelf-seasons-dev` вход, профиль и настройки onboarding сохраняются в Supabase; сами книги станут реальными на Stage 3.

## 5. Проверка проекта

```powershell
npm run typecheck
npm run lint
npm test
npm run release:check
```

## 6. Подключение аккаунтов

Выполни чек-лист `docs/STAGE_2_SETUP.md`. Он отдельно описывает dev-проект Supabase, миграцию, Google OAuth и проверку RLS.

## 7. GitHub

Репозиторий должен называться `shelf-seasons`. После добавления remote эта версия готова к обычному циклу commit → push → CI без дальнейшей передачи полного проекта архивами.
