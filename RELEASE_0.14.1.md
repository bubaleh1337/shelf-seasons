# Shelf Seasons 0.14.1

This visual patch protects book metadata from seasonal background artwork.

## Included

- quiet surface below every cover on Home and Library;
- status, language, season, title and author grouped on that surface;
- subtle border, blur and shadow in light and dark themes;
- detached autumn garland removed from desktop and mobile layouts.

No new Supabase migration or Vercel environment variable is required after 0.14.0.
