# Shelf Seasons 0.19.1

This patch polishes the yearly-goal actions on phones and shortens their
labels in both supported languages.

## Included

- `View goal` replaces the dynamic `View N reads` label;
- `Посмотреть цель` replaces `Посмотреть N чтений`;
- phone layouts stack both goal actions vertically at full card width;
- desktop layouts keep the compact horizontal actions.

## Manual setup

No Supabase migration and no new environment variable are required.
