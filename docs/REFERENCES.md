## Pre-launch research

Immediately before public launch or spending money, repeat:

- App Store and Google Play search for confusingly similar reading apps;
- GitHub and general web search for active software using the name;
- domain availability check;
- trademark search in intended launch markets.

The current planning name is a product direction, not legal clearance.
